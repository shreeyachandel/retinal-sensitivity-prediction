# Aggregate thesis results

These files are presentation outputs from the submitted thesis analysis. They
contain cohort-level metrics or aggregate visualisations only; no participant
identifiers, governed paths or source retinal images are included.

- `methodology_workflow.png`: conceptual analysis workflow.
- `primary_model_comparison.png`: participant-held-out MAE with participant-
  bootstrap 95% confidence intervals.
- `primary_observed_vs_predicted.png`: aggregate point-density panels.
- `primary_bland_altman.png`: aggregate agreement panels.
- `primary_model_metrics.csv`: selected primary metrics used in the README.

The original prediction rows, image-derived features and bootstrap draws remain
in the access-controlled research archive.
